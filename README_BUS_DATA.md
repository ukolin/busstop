# 広島バスナビ バス停・時刻表データ (JSON) 編集ガイド

本アプリのバス停情報および発車時刻表は、全て **JSON形式（`/src/data/busStops.json`）** に整理されています。
ファイル上で直接数値を書き換えるか、アプリ画面上の **「JSON」ボタン** から簡単に位置や時刻表を調整できます。

---

## 1. データファイルの場所

```text
/src/data/busStops.json
```

---

## 2. JSONデータの構造・サンプル

各バス停は以下のオブジェクトの配列として定義されています：

```json
[
  {
    "id": "stop-hiroshima-s1",
    "name": "広島駅（南口）",
    "nameKana": "ひろしまえき みなみぐち",
    "lat": 34.3975,
    "lng": 132.4751,
    "platform": "1番のりば (宇品・広島港方面)",
    "timetable": [
      {
        "id": "t-1",
        "routeNumber": "21号 宇品線",
        "company": "広島バス",
        "companyColor": "#dc2626",
        "destination": "広島港（宇品）行",
        "via": "八丁堀・御幸橋経由",
        "scheduledTime": "18:36",
        "minutesAway": 3,
        "delayMinutes": 2,
        "status": "approaching",
        "congestion": "medium",
        "barrierFree": true,
        "busId": "bus-21-1"
      }
    ]
  }
]
```

### 主要プロパティの説明

| フィールド | 型 | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| `id` | string | 一意のバス停ID | `"stop-hiroshima-s1"` |
| `name` | string | バス停名称 | `"広島駅（南口）"` |
| `nameKana` | string | ひらがな読み（検索用） | `"ひろしまえき みなみぐち"` |
| **`lat`** | **number** | **緯度（世界測地系 / WGS84）** | `34.3975` |
| **`lng`** | **number** | **経度（世界測地系 / WGS84）** | `132.4751` |
| `platform` | string | のりば番号・行先方面 | `"1番のりば (宇品・広島港方面)"` |
| `timetable` | array | 当該バス停から出発する時刻表配列 | `[...]` |

#### `timetable`（便情報）のプロパティ
- `routeNumber`: 路線番号（例: `"3号線"`, `"101号 エキまちループ"`）
- `company`: バス運行会社（`"広電バス"`, `"広島バス"`, `"広島交通"`, `"JRバス中国"`）
- `destination`: 行先（例: `"マリーナホップ行"`, `"広島港行"`）
- `via`: 主な経由地（例: `"紙屋町・市役所経由"`）
- `scheduledTime`: 定刻発車時刻（例: `"18:42"`）
- `minutesAway`: 到着・発車までの目安分数（数値）
- `delayMinutes`: 遅延分数（定時運行時は `0`）
- `status`: 運行状態（`"on_time"`: 定時, `"delayed"`: 遅延, `"approaching"`: まもなく接近, `"departed"`: 発車済）
- `congestion`: 車内混雑度（`"low"`: 空席あり, `"medium"`: やや混雑, `"high"`: 混雑）
- `barrierFree`: ノンステップ・スロープ対応（`true` / `false`）

## 3. バス停の位置（緯度・経度）を直す2つの方法

### 方法A: アプリ画面上で直す（おすすめ・直感的）
1. アプリ右上の **「JSON」** ボタン、または地図右側の **JSONアイコン** をクリックします。
2. 地図上の好きな位置をクリックすると、**「📍 クリック地点: 34.39..., 132.47...」** が表示されます。
3. モーダル内の「クリック座標を適用」ボタンを押すと、そのバス停の緯度・経度が一発で入力されます。
4. **「変更を保存」** を押せば、画面をリロードすることなく即座に地図上のピンの位置が移動します。
5. 更新したデータを永続化したい場合は、「JSON直接編集」タブから **「JSONコピー」** して `src/data/busStops.json` に上書き保存してください。

### 方法B: ファイル（`src/data/busStops.json`）を直接編集する
1. エディタで `src/data/busStops.json` を開きます。
2. 修正したいバス停の `lat` と `lng` の数値を書き換えて保存します。
